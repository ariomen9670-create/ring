# ♻️ SmartWaste – Waste Management System

## 📌 About the Project

SmartWaste is a simple web-based Waste Management System that helps citizens report waste problems, request waste pickup, and track their complaints.

It also helps administrators manage waste-related complaints and pickup requests from one place.

## 🎯 Problem

Waste-related problems like overflowing bins, garbage on roads, missed collection, and improper disposal are common.

SmartWaste provides a simple digital platform to report and manage these problems.

## 🚀 Features

- 👤 User Registration & Login
- 📸 Report Waste Issues
- 📍 Location/GPS Support
- 🚛 Waste Pickup Request
- 🔎 Complaint Tracking
- 📊 Admin Dashboard
- ♻️ Waste Awareness Section
- ⭐ Eco Points & Quiz
- 💬 User Feedback
- 🗺️ Waste Hotspot Monitoring
